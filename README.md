# 예능 기획안 Pre-viz 서비스

한국 방송사 예능 PD가 입력한 기획 아이디어를 **12개 프레임 텍스트 스토리보드**로 자동 변환해주는 사내 업무 도구입니다.

앱의 역할은 텍스트 스토리보드 생성까지이며, 실제 이미지·영상 생성은 PD가 완성된 스토리보드를 구글 Flow Omni에 직접 입력해 별도로 진행합니다(API 연동 없음).

## 무엇을 하는 앱인가요

- **예능 기획 아이디어 → 12프레임 자동 생성**: 제목 / 장르(프리셋 태그 + 직접 입력) / 시청 타깃 / 프로그램 개요를 입력하면, AI가 기승전결 순서에 맞는 12개 프레임을 만듭니다. 각 프레임은 구글 Flow Omni의 "정지 이미지 생성 → 그 이미지로 영상 생성" 2-step 워크플로우에 맞춰 `[IMAGE]`(정지 이미지 프롬프트) / `[VIDEO]`(카메라 무빙+동작) / `[AUDIO]`(앰비언스·SFX) 3필드로 분리해 작성됩니다.
- **캐릭터(출연진) 일관성**: 인물 사진을 올리면 AI가 외형을 묘사한 텍스트를 만들고, 이를 12프레임 전체에 자동으로 반영해 같은 인물이 유지되도록 합니다. 사진 원본은 저장하지 않습니다.
- **레퍼런스 예능 반영**: 참고하고 싶은 예능의 이름과 장면 이미지를 넣으면, 그 촬영 톤앤매너(색감·조명·구도)만 텍스트로 뽑아 스토리보드에 참고 자료로 반영합니다(스토리·소재는 베끼지 않도록 프롬프트로 제어).
- **프레임 개별 재생성**: 마음에 들지 않는 프레임만 골라 다시 만들 수 있고, 방금 재생성한 내용은 1단계 되돌리기가 가능합니다.
- **렌더 안정성 방어**: 화면 속 글자·워터마크·촬영 스태프 노출을 금지하고, 인물의 발화(대사) 묘사 대신 표정·비언어적 제스처로 자동 치환해, 구글 Flow Omni에서 얼굴이 뭉개지는 렌더 오류를 방지합니다.
- **내보내기**: 완성된 스토리보드를 한국어 화면 그대로 프레임별/전체 복사하거나, 구글 Flow Omni에 바로 붙여넣을 수 있도록 영어로 자동 번역된 텍스트로 복사·`.txt` 다운로드할 수 있습니다.

## 기술 스택

- **[Next.js](https://nextjs.org)** — 화면(UI)과 API 라우트를 한 프로젝트에서 처리
- **[OpenAI API](https://platform.openai.com)** (`gpt-4o-mini`) — 스토리보드 텍스트 생성, 인물·레퍼런스 이미지 묘사(비전), 영문 번역
- **[zod](https://zod.dev)** — AI 응답이 12프레임·100자 이상·짝수 초 등 필수 규칙을 지켰는지 검증
- **Tailwind CSS** — 화이트 배경 + ENA Blue(`#2c24ce`) 포인트 컬러
- **브라우저 `localStorage`** — 별도 서버 DB 없이 마지막 작업 내용을 저장
- **[Vercel](https://vercel.com)** — 배포

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

### 환경 변수

루트에 `.env` 파일을 만들고 아래 값을 채워야 합니다(저장소에는 포함되어 있지 않습니다).

| 변수명 | 용도 |
|---|---|
| `OPENAI_API_KEY` | 스토리보드 생성·이미지 묘사·번역에 사용하는 OpenAI API 키 |
| `APP_ACCESS_PIN` | 화면 접근을 제한하는 공유 비밀번호(PIN) — 계정 로그인 없이 이 값 하나로 접근을 제어합니다 |

## 접근 제어 & 데이터 보관

- 계정 로그인 없이 공유 비밀번호(PIN) 하나로 화면 접근을 제한합니다.
- 서버 데이터베이스를 두지 않습니다 — 마지막 작업 스토리보드는 브라우저 `localStorage`에만 저장됩니다.
- 인물 사진·레퍼런스 이미지 원본은 어디에도 저장하지 않습니다 — 묘사 생성 1회 호출에만 쓰이고 사라집니다.
